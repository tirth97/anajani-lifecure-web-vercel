# Anjani Lifecure Sciences

Marketing website for Anjani Lifecure Sciences — a curated portfolio of quality pharmaceutical products marketed to healthcare providers across India.

## Tech stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui

## Local development

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:8080/.

## Build

```sh
npm run build
```
